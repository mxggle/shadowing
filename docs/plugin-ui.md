# 插件在界面里放在哪里：方案

[Shadowing 插件界面方案](https://claude.ai/artifact/7Us6hgeeh8bx5SYVUNoSmW) 上。插件系统本身见 [plugin-plan.md](plugin-plan.md)。_

## 问题

现在 YouTube 导入的入口是侧栏顶上的一个链接图标。再装一个插件，就得再加一个图标；侧栏顶一共 248px，已经有 4 个图标，
句子行的悬停工具条最多也已经有 6 个。按插件加图标走不远，而且每个插件都会把界面改得不一样。

## 原则

1. **插件不画界面**。插件只在 manifest 里声明“往哪个插槽放什么”（一句话、可选的 lucide 图标名、出现条件），
   应用按自己的样式画出来。插件不能在工具条、顶栏、侧栏顶加图标，也不能带自己的图片或颜色。
2. **只有 8 个插槽**，每个插槽都写好了“放不下怎么办”。
3. **没装插件时不出现空位**：没有插件的条目，插槽就保持现在的样子（菜单只剩内置项，⋯ 和后台任务不出现）。
4. **看得出是谁加的**：菜单里内置项在上，插件项在下，按插件分组，组名是插件名；命令面板里插件项右边写插件名。
5. **⌘K 兜底**：任何插槽里放不下、收起来的，在 ⌘K 里都搜得到。
6. 颜色规矩不变：橙色只表示循环；“需要注意”用已有的 `warn`，出错用 `danger`。

## 8 个插槽

| # | 插槽 | 在哪里 | 放什么 | 放不下时 |
| --- | --- | --- | --- | --- |
| ① | 添加 | 侧栏顶的「＋」（代替现在的链接图标和「打开其他文件夹」图标） | 导入方式。所有“粘贴链接”的导入合成一项「从链接导入… ⌘V」，下面一行小字列出支持的网站；不是链接的导入（订阅播客）各占一项，小字写插件名。下面是「打开其他文件夹…」「更多导入方式…」 | 菜单可以滚动；导入方式超过 6 项时按插件收成二级菜单 |
| ② | 列表里的下载 | 曲目列表里，音频要去的那个分组 | 导入一开始，新音频就以“下载中”的一行出现（进度环、`下载音频 4.2 / 11.3 MB`），排队的写“等前一个下载完”，失败的写原因加「再试一次 / 不要了」。完成后变成普通的一行 | 一行一个，多少都放得下（以后的播放列表导入也一样）。代替现在列表顶上的那张卡片 |
| ③ | 音频的 ⋯ | 主区标题行的图标最后 | 对整个音频的操作。内置：导入其他字幕文件…、移除字幕、在 Finder 中显示（前两项从图标收进来）；插件：导出到 Anki…、重新获取 YouTube 字幕、打开原视频 | 每个插件最多直接放 3 项，再多收成「插件名 ›」 |
| ④ | 句子的 ⋯ | 句子行悬停工具条的最后；右键也打开同一个菜单 | 对这一句的操作。内置：复制这一句；插件：加入 Anki、换一个声音读 | 同 ③。没有插件给句子加操作时不出现 ⋯（右键菜单照常有内置项） |
| ⑤ | 选中文字 | 选中句子里的字以后浮出的小工具条 | 内置的查词在前，词典插件在后，最后是复制 | 最多 3 个，其余进 ⋯。等选词查词做了再做 |
| ⑥ | 后台任务 | 顶栏，学习记录圆环左边；只在有任务时出现，带数量 | 所有在后台跑的事：下载、导出、转写、模型下载，每项写着是谁发起的，可以取消；完成的留一会儿，可以直接打开结果 | 列表可以滚动 |
| ⑦ | 命令面板 | ⌘K，或者顶栏的放大镜 | 所有内置操作和插件操作，按“这个音频 / 当前句 / 添加 / 设置”分组 | 搜索 |
| ⑧ | 设置 → 插件 | 设置加左侧导航（入门、AI 功能、录音、插件、关于） | 已安装 / 浏览。每个插件一页：状态、选项、它会做什么、占用、更新、删除 | 列表 |

另外一处不算插槽的：粘贴的链接没有插件能处理时，导入确认框里推荐市场里能处理它的插件，「安装并读取这个链接」。

## 和现在比，要改的地方

- 侧栏顶：去掉链接图标和「打开其他文件夹」图标，换成「＋」。图标数从 4 个（装了插件是 5 个）变成固定的 4 个。
- 列表顶上的导入卡片换成列表里的“下载中”一行（插槽 ②）。
- 字幕标题行：导入字幕、移除字幕两个图标收进 ⋯。
- 句子行：有插件给句子加了操作时，工具条最后多一个 ⋯；加右键菜单。
- 顶栏：加后台任务圆环（有任务时）和放大镜（⌘K）。现在转写的进度在主区的卡片里、模型下载在设置里，这两样也进后台任务。
- 设置：内容变多以后加左侧导航；插件一栏变成单独的一页。

## manifest 里怎么声明

在 `contributes` 里加两样（`importers` 已有）：

```json
"contributes": {
  "importers": [ … ],
  "commands": [
    { "id": "export-track", "title": "把这个音频的句子导出到 Anki…", "icon": "layers", "in": ["track", "palette"] },
    { "id": "add-sentence", "title": "加入 Anki", "icon": "layers", "in": ["sentence", "palette"] },
    { "id": "refetch-subtitles", "title": "重新获取字幕", "in": ["track"], "when": "importedBy:self" }
  ],
  "settings": [
    { "key": "subtitles", "type": "toggle", "label": "有人工字幕时一起下载", "default": true },
    { "key": "folder", "type": "text", "label": "默认存到", "default": "YouTube" },
    { "key": "cookies", "type": "select", "label": "YouTube 要求登录时", "options": ["不借用", "Chrome", "Safari", "Firefox"], "default": "不借用" }
  ]
}
```

- `in`：放进哪些插槽（`track` ③、`sentence` ④、`selection` ⑤、`palette` ⑦）。②⑥ 不用声明：插件跑任务时报告进度就会出现在那里。
- `when`：只在某些情况出现，先只支持几种固定的（`importedBy:self` = 这个音频是本插件导入的、`hasTranscript`）。不做表达式。
- `icon`：lucide 的图标名，应用只认白名单里的。
- 插件不能自己定全局快捷键（会和应用的冲突）；以后可以让用户在 ⌘K 里给命令设快捷键。
- `settings` 的类型：`toggle`、`select`、`text`、`secret`（存钥匙串，插件启动时传给它）。设置页由应用画。
- 运行命令时，应用把上下文（这一句的文字和时间、解释、切好的音频片段的副本）放进暂存文件夹交给插件，不给用户文件夹的路径。
- 插件可以报告一行状态（`status`：一句话 + 正常 / 需要注意），显示在已安装列表和它的页面上。
