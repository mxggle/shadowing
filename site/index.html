一句一句，跟读你自己的音频。

把教材 CD、有声书或播客拖进来，Shadowing 在你的 Mac 上把它转写成一句一句。点一句就循环这一句，放慢也不变调，听不懂就展开看解释。

    拖进一段音频，它就变成一句一句

    手里有字幕就直接用；没有，就在这台 Mac 上转写。

    本机转写
    用 Whisper 在 Mac 上转写，Apple Silicon 加 Metal，不用 API Key，音频不上传。想要更快也可以选 Groq、OpenAI 等云端服务。
    按停顿断句
    句子边界对齐到录音里真实的停顿，循环一句时不会从上一句的尾巴开始。
    区分说话人
    AB 对话里谁说了哪句会分开标出，声纹也在本机运算。
    没把握的字
    转写时不确定的字画上虚线，比如 しだ，校对时一眼就能看到。可以直接改，查找并全部替换，或者让 AI 校对给出建议，由你确认。
    已有字幕
    音频旁边同名的 SRT、VTT 会自动读取。修改只存在应用里，不改动你的原文件。

    一句话，练到说得出来为止

    跟读要的是同一句听很多遍。这些都为这件事服务。

    循环一句
    点一句就从这一句开始。按 L 循环，[ ] 换句，旁边记着这一句已经听了几遍。
    变速不变调
    0.5× 到 2.0×，每次 0.05。速度是全局的，换一个音频也不用重设。
    A–B 循环
    不按句子也可以：L 依次设 A、设 B，A 和 B 还能以 0.1 秒微调。
    解释这一句
    译文、生词、语法和口语点，答案会存下来。用你自己选的模型：OpenAI、Anthropic、Gemini、DeepSeek、OpenRouter，本机的 Ollama、LM Studio，或者直接用 ChatGPT 账号登录。
    记住进度
    每个音频听到哪里都记得，接着听时回退 2 秒，方便接上。

    每天练一点，看得见自己在进步

    应用按你真正在练的时间计时，给自己定个每日目标，顶栏的圆环会慢慢填满。

    播放时计时，暂停后 90 秒内还在操作也算在练。每天从凌晨 4 点算起，熬夜练的也算当天。

    你的音频留在你的 Mac 上

    没有字幕、没有模型、没有 API Key 时，播放器照样完整可用。AI 都是可选的。

    • 只访问你选择的文件夹。加上应用自带的示例，其他文件一概不碰。
    • 没有遥测。只有你用到 AI 功能时才联网，设置里每个功能都写明内容发到哪里。
    • Key 存在 macOS 钥匙串里。应用自己的数据里只留 sk-…abcd 这样的提示。
    • 本机模型第一次用到时才下载。固定版本，并校验 SHA-256。

    安装

    目前只有 Apple Silicon 的 macOS 版（macOS 11 及以上）。Windows 和 Linux 版正在开发中，敬请期待；在 GitHub 上关注仓库，发布时会第一时间收到通知。

    1. 下载安装包

      点这里 下载最新版安装包，大约 11 MB。

    2. 拖进“应用程序”

      双击下载的 .dmg，在打开的窗口里把 Shadowing 拖到“应用程序”文件夹。

    3. 第一次打开

      这个版本还没有 Apple 开发者签名，系统会拦一下。到“系统设置 → 隐私与安全性”点“仍要打开”，或者在终端运行：

      xattr -dr com.apple.quarantine /Applications/Shadowing.app

    4. 以后自动更新

      打开应用时会检查新版本，看过更新说明后点“更新并重新打开”就行，下载的安装包会先校验签名。菜单和设置里也能手动“检查更新…”。
